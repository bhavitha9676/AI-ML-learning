# Project Requirements – Expense Tracker

## 1. Project Title

**Expense Tracker**

## 2. Project Description

**Expense Tracker** is a Python-based application used to record and manage daily expenses.

The application allows users to:

* Add expenses
* View expenses
* Search expenses
* Update expenses
* Delete expenses
* Calculate expense summaries
* Generate monthly reports

## 3. Objectives

The main objectives of the project are:

* Create an expense management application using Python.
* Store expenses in a CSV file.
* Add, view, search, update, and delete expenses.
* Calculate total and average expenses.
* Generate category-wise and monthly summaries.
* Validate user input.
* Perform basic unit testing.

## 4. Features

The application provides the following features:

* **Add Expense**
* **View Expenses**
* **Search Expense**
* **Update Expense**
* **Delete Expense**
* **Expense Summary**
* **Monthly Report**
* **Generate Reports**
* **Input Validation**
* **CSV File Storage**

## 5. Technologies Used

| Technology   | Purpose                             |
| ------------ | ----------------------------------- |
| Python       | Application development             |
| CSV          | Expense data storage                |
| Unittest     | Unit testing                        |
| VS Code      | Development environment             |
| Git & GitHub | Version control and project hosting |

## 6. Expense Details

Each expense contains the following information:

| Field              | Description           |
| ------------------ | --------------------- |
| **ID**             | Unique expense ID     |
| **Date**           | Date of expense       |
| **Category**       | Expense category      |
| **Description**    | Expense details       |
| **Amount**         | Money spent           |
| **Payment Method** | Cash, UPI, Card, etc. |

## 7. Categories

The application supports the following expense categories:

* Food
* Travel
* Shopping
* Bills
* Education
* Entertainment
* Health
* Other

## 8. Requirements

The application requires:

* **Python 3.x**
* **VS Code**
* Basic knowledge of Python
* Git and GitHub for version control

## 9. Expected Result

The application should allow users to easily manage their daily expenses and view useful expense summaries and reports.

The system should provide reliable expense storage, data management, input validation, and basic reporting functionality.

## 10. Future Enhancements

The application can be enhanced by adding:

* GUI application
* Database integration
* Expense charts and visualizations
* Login and authentication system
* Excel/PDF report generation
* Web-based application

## 11. Conclusion

The **Expense Tracker** provides a simple and practical way to manage daily expenses while demonstrating important Python programming concepts.

The project provides hands-on experience with **Python, file handling, CSV data management, input validation, unit testing, Git, GitHub, and project documentation**.
